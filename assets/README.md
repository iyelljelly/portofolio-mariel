# Assets folder

Drop your real files here, then update the matching spot in `index.html`:

- `img/mariel-hero.jpg` → your hero photo. Swap it into the placeholder div inside
  the `#hero` section (look for `[ Drop your favorite photo here ... ]`).
- `img/` → any project screenshots (TITU, Un-Loop, WISE, Beyond the Gear) to replace
  the dashed "Project Spec" placeholder boxes inside each project detail block.
- `img/certs/` → certificate scans to replace the "Certificate Scan Placeholder" boxes
  in the Certificates & Credentials section.
- `cv/Mariel-Fang-CV.pdf` → your actual CV file. The hero "Download CV" button already
  points at `assets/cv/Mariel-Fang-CV.pdf`, so just drop a file with that exact name here
  and the button will work immediately.
- `icons/` → if you'd rather use real logo images (Excel, Oracle, etc.) instead of the
  Material Symbols icons currently used in the "About" skills grid, drop them here and
  tell Kiro which icon maps to which skill tile.

You don't need to touch any code to add these — just upload the files into the right
folder and let Kiro know, or ask Kiro to wire up a specific file once it's here.
